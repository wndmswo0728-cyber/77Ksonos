# PF ON · Hopping ON 빌드 (SONOS · TANOS · TANS, 77 K · 300 K)

## 실행
1. 각 폴더를 DeckBuild 작업 폴더로 지정하고 `ALL_IV.in`을 실행한다.
   - 300 K 덱 3개를 먼저 돌린다(빠름).
   - 다음에 77 K 덱 3개를 돌린다(300→77 K 냉각 단계 때문에 느림).
2. 실행이 끝나면 폴더째 올린다.

원본 패키지(`ChargeTrap_77K_Ready_To_Run.zip`)에서 계산 절차만 바꿨다. 전하·모델·메시는 같다.
- `models` 문을 `contact` 앞으로 옮김
- 드레인 전압을 0.0001 → 0.001 → 0.01 → 0.1 V로 나눠 올림
- Vt 추출 추가 (`Vt_summary.dat`, `<상태>_IdVg.dat`)
